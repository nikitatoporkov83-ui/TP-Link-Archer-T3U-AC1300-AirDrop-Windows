Пульсар для Windows x64 — тестовая сборка

Подключите один TP-Link Archer T3U с USB ID 2357:012d. Комплект включает приложение, Python, .NET, TAP-Windows6 и помощник USB-драйвера. На iPhone ничего устанавливать не требуется.

Настройка переводит выделенный адаптер TP-Link в WinUSB: обычный Wi-Fi через него становится недоступен. Исходный драйвер сохраняется заранее; совместимый встроенный драйвер Windows остаётся доступен. Пуск → Пульсар → Восстановить драйвер Wi-Fi возвращает обычный режим. Другие USB-адаптеры и Intel Bluetooth не являются целью настройки.

USB-помощник использует libwdi для локального создания подписанного каталога устройства и существующий системный WinUSB. Windows может запросить подтверждение драйвера или сертификата. Имеющиеся WinUSB и awdl0 используются повторно.

Обычно Bluetooth остаётся включённым. Если Windows блокирует объявление, приложение сначала повторяет попытку без перезапуска. Явное восстановление может ненадолго отключить аксессуары, затем возвращает исходные состояния служб.

Файлы до 1 ГиБ передаются потоково с временными файлами и ограниченной памятью. Оставьте достаточно места для архива и распаковки. Входящие файлы требуют подтверждения. Держите iPhone разблокированным с AirDrop «Для всех на 10 минут». Прерванный файл не показывается как завершённый.

Сборка не подписана и не проверена на чистом втором ПК. Состояние аппаратных проверок описано в документации. При удалении сохраняются полученные файлы и резервные копии драйвера.
