# Работа в облачной среде

Используйте существующий каталог
`/workspace/TP-Link-Archer-T3U-AC1300-AirDrop-Windows`.
Каждая облачная задача уже изолирована: дополнительный Git worktree
создавать не требуется, если пользователь явно не попросил об этом.

## Настройка Git

Нужны Bash и Git версии 2.30 или новее. Выполните:

```bash
cd /workspace/TP-Link-Archer-T3U-AC1300-AirDrop-Windows
bash scripts/setup-cloud.sh
```

Скрипт добавляет правило получения веток, обновляет сведения с GitHub
и проверяет наличие `origin/main`. Его можно выполнять повторно.
Он не переключает рабочую ветку, не меняет файлы проекта и не отправляет
коммиты на GitHub.

Используйте встроенный HTTPS-доступ к GitHub. Отсутствие переменной
`GITHUB_TOKEN` само по себе не означает, что доступ не настроен.

## Начало задачи

Прочитайте README и проверьте состояние:

```bash
cd /workspace/TP-Link-Archer-T3U-AC1300-AirDrop-Windows
git status --short --branch
git fetch origin
git show-ref --verify refs/remotes/origin/main
```

Основная ветка GitHub — `main`. Сохраняйте ветку, выделенную для текущей
задачи, и пользовательские изменения. Переключайтесь на `main` только
когда это нужно для задачи и рабочий каталог позволяет это сделать.
Не применяйте сброс изменений или принудительную отправку для настройки.

## Проверки и ограничения

Пока в проекте нет исходников приложения, манифестов зависимостей,
сборки, тестового набора или сервисов. Для текущей работы достаточно Git;
установка дополнительных пакетов не требуется.

Для изменений документации и настроек проверяйте `git diff --check`.
После добавления кода настройте инструменты и тесты по его манифестам.

Облачная машина работает на Linux. Проверки USB-адаптера, драйверов Windows
и совместимости с AirDrop на целевом оборудовании здесь не выполнялись.
