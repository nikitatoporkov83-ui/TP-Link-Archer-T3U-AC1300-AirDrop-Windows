# Источник исходного кода

- Проект: [PulseIt — gsl0001/windows-airdrop](https://github.com/gsl0001/windows-airdrop).
- Зафиксированный коммит: `2b336953460820e3880bb83cef8bd4acc15cf584`.
- Перенесены все 124 отслеживаемых файла этого коммита.
- История Git и локальные результаты сборки исходного репозитория не копируются.

При первичном импорте логика приложения и тесты были сохранены без изменений.
Затем приложение переименовано в «Пульсар»: добавлены русский интерфейс,
сообщения, документация, культура ru-RU и проверки локализации.
Машинные ключи протокола и разделение радиодвижков сохранены. В README добавлены ссылки
на этот репозиторий и его облачные инструкции; правила `.gitignore` дополнены
нашими исходными правилами. Сохранены `.editorconfig` и наша начальная настройка
Git. Предыдущий README доступен в [истории настройки](project-initialization.md).

Лицензионные условия и авторские уведомления сохранены. Описания LICENSE
и THIRD_PARTY_NOTICES.md переведены; полные тексты GPL/MIT оставлены в оригинале. Библиотеки OWL и devourer загружаются скриптами исходного проекта
по закреплённым версиям; они не входили в его отслеживаемые файлы.

В исходном проекте указан Archer T3U с USB ID `2357:012d`.
Другие аппаратные ревизии автор не квалифицировал. Перед использованием
проверьте USB ID своего адаптера.

## Проверка в облачной среде

Python 3.12, зависимости установлены из `installer/requirements.txt`.
После переноса обнаружено 57 тестов: 51 прошёл, 6 Windows-проверок
пропущены штатными условиями тестового набора. Те же результаты получены
до переноса в исходном снимке PulseIt.

Эта проверка не подтверждает работу адаптера, Bluetooth или обмен с iPhone.
После локализации Windows-проекты проверяются кросс-сборкой в Linux.
Запуск интерфейса Windows и аппаратные проверки в Linux не выполнялись.
Для Windows используйте [исходную инструкцию сборки](build.md).
